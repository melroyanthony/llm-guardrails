# Container Setup: Angular on ECS Fargate

Full container configuration for serving an Angular SPA with nginx on ECS Fargate. Covers the multi-stage Dockerfile, nginx config, runtime environment injection, ALB health checks, and CloudWatch logging.

## Multi-Stage Dockerfile

Two stages: `node:22-alpine` to build the Angular app, `nginx:alpine` to serve it.

```dockerfile
# apps/shell/Dockerfile

# ─────────────────────────────────────────
# Stage 1: Build Angular application
# ─────────────────────────────────────────
FROM node:22-alpine AS builder

WORKDIR /workspace

# Copy workspace manifests — cache npm install layer separately
COPY package.json package-lock.json* ./
COPY apps/shell/package.json ./apps/shell/
COPY libs/ ./libs/
COPY nx.json tsconfig.base.json ./

# Install all workspace dependencies
RUN npm ci --prefer-offline

# Copy application source
COPY apps/shell/ ./apps/shell/

# Build production bundle
# Output: dist/apps/shell/browser/ (static), dist/apps/shell/server/ (SSR, if enabled)
RUN npx nx build shell --configuration=production

# ─────────────────────────────────────────
# Stage 2: Production nginx image
# ─────────────────────────────────────────
FROM nginx:1.27-alpine AS production

# Install curl (for health check command alternative), gettext (for envsubst), and jq (for safe env.js generation)
RUN apk add --no-cache curl gettext jq

# Copy nginx site config template — envsubst fills in variables at container startup
COPY apps/shell/nginx.conf.template /etc/nginx/conf.d/default.conf.template

# Copy built Angular static files
COPY --from=builder /workspace/dist/apps/shell/browser /usr/share/nginx/html

# Copy entrypoint script (generates env.js at container startup)
COPY apps/shell/docker-entrypoint.sh /docker-entrypoint.sh
RUN chmod +x /docker-entrypoint.sh

# Run as non-root for security
# nginx official image already has a 'nginx' user; grant it the directories it needs
RUN chown -R nginx:nginx /usr/share/nginx/html \
    && chown -R nginx:nginx /var/cache/nginx \
    && chown -R nginx:nginx /var/log/nginx \
    && chown -R nginx:nginx /etc/nginx/conf.d \
    && touch /var/run/nginx.pid \
    && chown nginx:nginx /var/run/nginx.pid

USER nginx

# Use port 8080 for non-root nginx. The ALB maps external port 80/443 to container port 8080.
EXPOSE 8080

ENTRYPOINT ["/docker-entrypoint.sh"]
```

Build and push to ECR:
```bash
# Authenticate
aws ecr get-login-password --region us-east-1 \
  | docker login --username AWS --password-stdin <account>.dkr.ecr.us-east-1.amazonaws.com

# Build from monorepo root (required — Dockerfile references workspace paths)
docker build -f apps/shell/Dockerfile -t my-app/shell:latest .

# Tag and push

docker push <account>.dkr.ecr.us-east-1.amazonaws.com/shell:latest
```

## nginx.conf for SPA Routing + API Proxy

```nginx
# apps/shell/nginx.conf.template
# Use port 8080 for non-root nginx. The ALB maps external port 80/443 to container port 8080.
server {
    listen       8080;
    server_name  _;
    root         /usr/share/nginx/html;
    index        index.html;

    # ─── Compression ─────────────────────────────────────
    gzip              on;
    gzip_vary         on;
    gzip_min_length   1024;
    gzip_proxied      any;
    gzip_comp_level   6;
    gzip_types
        text/plain
        text/css
        text/javascript
        application/javascript
        application/json
        application/xml
        image/svg+xml
        font/woff2;

    # ─── Security Headers ─────────────────────────────────
    add_header X-Frame-Options           "SAMEORIGIN"                     always;
    add_header X-Content-Type-Options    "nosniff"                        always;
    add_header X-XSS-Protection          "1; mode=block"                  always;
    add_header Referrer-Policy           "strict-origin-when-cross-origin" always;
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    # CSP: 'self' allows env.js since it's served from the same origin.
    # For production, consider adding nonces or SRI hashes for stricter CSP.
    add_header Content-Security-Policy
        "default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data: https:; connect-src 'self' https:;"
        always;

    # ─── ALB Health Check ────────────────────────────────
    # ALB probes this path every 15s; must return 200 quickly
    location = /health {
        access_log  off;
        return      200 "OK\n";
        add_header  Content-Type text/plain;
    }

    # ─── Runtime Environment ─────────────────────────────
    # env.js is generated by docker-entrypoint.sh at container start
    # Must not be cached — different environments inject different values
    location = /env.js {
        expires   off;
        add_header Cache-Control "no-store, no-cache, must-revalidate, proxy-revalidate";
    }

    # ─── API Proxy (optional) ────────────────────────────
    # Use this if Angular calls relative /api/* URLs to avoid CORS.
    # Skip this block if Angular calls the API Gateway URL directly from env.js.
    location /api/ {
        proxy_pass              ${API_UPSTREAM}/;
        proxy_set_header        Host              $proxy_host;
        proxy_set_header        X-Real-IP         $remote_addr;
        proxy_set_header        X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header        X-Forwarded-Proto $scheme;
        proxy_read_timeout      30s;
        proxy_connect_timeout   5s;
        proxy_buffering         off;
    }

    # ─── Static Assets (JS, CSS, images, fonts) ──────────
    # Angular CLI adds content hash to filenames; cache indefinitely
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot|map)$ {
        expires       1y;
        add_header    Cache-Control "public, immutable";
        access_log    off;
    }

    # ─── SPA Fallback ────────────────────────────────────
    # All unmatched routes serve index.html — Angular router handles navigation
    location / {
        try_files   $uri $uri/ /index.html;
        add_header  Cache-Control "no-store, no-cache, must-revalidate";
    }
}
```

Note: `$API_UPSTREAM` must be set as an nginx variable via the entrypoint (see below) or as a hardcoded value in a Terraform template. If Angular calls the API Gateway URL directly using the value from `env.js`, the `/api/` proxy block is unnecessary.

## Runtime Environment Injection

### docker-entrypoint.sh

The entrypoint runs before nginx starts. It reads ECS task environment variables and writes them into `env.js`, which nginx serves as a static file.

```sh
#!/bin/sh
# apps/shell/docker-entrypoint.sh
# Runs as the nginx user at container startup.

set -eu

ENV_JS_PATH=/usr/share/nginx/html/env.js

echo "Generating runtime environment..."

# Write env.js from ECS task environment variables using jq for safe JSON generation.
# This prevents injection attacks from values containing quotes, newlines, or special characters.
# Angular reads window.__env at bootstrap (see runtime-env.ts).
jq -n \
  --arg apiUrl "${API_URL:-https://api.example.com}" \
  --arg authClientId "${AUTH_CLIENT_ID:-}" \
  --arg env "${ENVIRONMENT:-production}" \
  --arg appVersion "${APP_VERSION:-unknown}" \
  --argjson features "$(echo "${FEATURE_FLAGS:-{}}" | jq '.' 2>/dev/null || echo '{}')" \
  '{API_URL: $apiUrl, AUTH_CLIENT_ID: $authClientId, ENVIRONMENT: $env, APP_VERSION: $appVersion, FEATURE_FLAGS: $features}' \
  | jq -c '.' \
  | { read -r json_val; printf 'window.__env = %s;\n' "$json_val"; } \
  > "$ENV_JS_PATH"

# Log generation confirmation without dumping values (may contain sensitive config)
echo "env.js generated ($(wc -c < "$ENV_JS_PATH") bytes)"

# Set nginx API upstream variable if the proxy block is used.
# If not using nginx proxy, remove the export below.
export API_UPSTREAM="${API_URL:-https://api.example.com}"

# Process the nginx config template — substitutes ${API_UPSTREAM} with its runtime value.
# nginx cannot evaluate shell variables directly; envsubst is required.
envsubst '${API_UPSTREAM}' < /etc/nginx/conf.d/default.conf.template > /etc/nginx/conf.d/default.conf

# Start nginx in the foreground (required for Docker — process must not daemonize)
exec nginx -g "daemon off;"
```

Make it executable in version control:
```bash
chmod +x apps/shell/docker-entrypoint.sh
git update-index --chmod=+x apps/shell/docker-entrypoint.sh
```

### Angular Runtime Env Module

```typescript
// apps/shell/src/environments/runtime-env.ts
declare global {
  interface Window { __env: RuntimeEnv; }
}

export interface RuntimeEnv {
  API_URL: string;
  AUTH_CLIENT_ID: string;
  ENVIRONMENT: 'development' | 'staging' | 'production';
  APP_VERSION: string;
  FEATURE_FLAGS: Record<string, boolean>;
}

const defaults: RuntimeEnv = {
  API_URL:       'http://localhost:3001',
  AUTH_CLIENT_ID: '',
  ENVIRONMENT:   'development',
  APP_VERSION:   'local',
  FEATURE_FLAGS: {},
};

// SSR safe — window is undefined in Node.js server rendering
export const runtimeEnv: RuntimeEnv =
  typeof window !== 'undefined' && window.__env ? window.__env : defaults;
```

```html
<!-- apps/shell/src/index.html — load env.js BEFORE main bundle -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>My App</title>
    <base href="/" />
    <!-- Runtime environment — generated at container startup -->
    <script src="/env.js"></script>
  </head>
  <body>
    <app-root></app-root>
  </body>
</html>
```

## Docker Build Args vs Runtime Env

| Variable Type | Set Via | Visible In | Use For |
|---|---|---|---|
| Build arg (`ARG`) | `docker build --build-arg` | `docker history` | NODE_ENV, build-time optimizations |
| Runtime env (`ENV`) | ECS task definition | Container env | API_URL, feature flags, auth config |
| Secret | ECS secrets (SSM/Secrets Manager) | Not in task definition | AUTH_CLIENT_ID, API keys |

```dockerfile
# Correct: build-time only
ARG NODE_ENV=production
ARG BUILD_DATE

# Wrong: forces image rebuild to change API URL
ARG API_URL=https://api.example.com

# Correct: empty default at build time; filled by entrypoint at runtime
ENV API_URL=""
ENV AUTH_CLIENT_ID=""
ENV ENVIRONMENT="production"
ENV APP_VERSION="unknown"
```

## ECS Task Definition (Terraform — Full Container Block)

```hcl
resource "aws_ecs_task_definition" "frontend" {
  family                   = "${var.app_name}-frontend"
  network_mode             = "awsvpc"
  requires_compatibilities = ["FARGATE"]
  # Small SPA:  512  CPU / 1024 MB memory
  # Medium SPA: 1024 CPU / 2048 MB memory (large bundle or SSR)
  cpu    = 512
  memory = 1024

  execution_role_arn = aws_iam_role.ecs_execution.arn
  task_role_arn      = aws_iam_role.ecs_task.arn

  container_definitions = jsonencode([{
    name      = "frontend"
    image     = "${aws_ecr_repository.frontend.repository_url}:${var.image_tag}"
    essential = true

    portMappings = [{ containerPort = 8080, protocol = "tcp" }]

    # Runtime values — same image, different values per environment
    environment = [
      { name = "API_URL",     value = var.api_gateway_url },
      { name = "ENVIRONMENT", value = var.environment },
      { name = "APP_VERSION", value = var.image_tag },
    ]

    # Sensitive values fetched from SSM at task launch — not visible in task definition
    secrets = [
      { name = "AUTH_CLIENT_ID", valueFrom = var.auth_client_id_ssm_arn },
    ]

    # Health check: start period 60s gives nginx and env.js time to initialize
    healthCheck = {
      command     = ["CMD-SHELL", "curl -fsS http://localhost:8080/health || exit 1"]
      interval    = 30
      timeout     = 5
      retries     = 3
      startPeriod = 60
    }

    # awslogs sends stdout/stderr to CloudWatch Logs
    # nginx official image symlinks access.log -> /dev/stdout, error.log -> /dev/stderr
    logConfiguration = {
      logDriver = "awslogs"
      options = {
        "awslogs-group"         = "/ecs/${var.app_name}/frontend"
        "awslogs-region"        = var.aws_region
        "awslogs-stream-prefix" = "frontend"
        "awslogs-create-group"  = "true"
      }
    }

    # Allow in-flight requests to drain before the container is stopped
    stopTimeout = 30
  }])
}
```

## ALB Target Group (Terraform)

```hcl
resource "aws_lb_target_group" "frontend" {
  name        = "${var.app_name}-frontend-tg"
  port        = 8080
  protocol    = "HTTP"
  vpc_id      = var.vpc_id
  target_type = "ip"     # Fargate tasks register their ENI IPs, not EC2 instances

  health_check {
    enabled             = true
    path                = "/health"
    port                = "traffic-port"
    protocol            = "HTTP"
    healthy_threshold   = 2
    unhealthy_threshold = 3
    interval            = 15
    timeout             = 5
    matcher             = "200"
  }

  # 30s deregistration — enough for a static SPA (no long-lived WebSocket connections)
  deregistration_delay = 30

  tags = var.common_tags
}
```

## CloudWatch Logging

nginx's official image routes access and error logs to stdout/stderr via symlinks. The `awslogs` driver in the ECS task definition captures both streams automatically.

```hcl
resource "aws_cloudwatch_log_group" "frontend" {
  name              = "/ecs/${var.app_name}/frontend"
  retention_in_days = 30

  tags = var.common_tags
}
```

Log group naming convention: `/ecs/<app-name>/<service-name>`

Useful CloudWatch Logs Insights queries:

```
# Monitor nginx 5xx error rate
fields @timestamp, @message
| filter @message like /HTTP\/1\.[01]" 5[0-9]{2}/
| stats count(*) as errors by bin(5m)
| sort @timestamp desc

# Find slow responses (> 1s)
fields @timestamp, @message
| filter @message like /request_time/ and @message like /[1-9]\.[0-9]/
| sort @timestamp desc
| limit 50
```
