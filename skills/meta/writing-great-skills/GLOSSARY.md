# Glossary — Writing Great Skills

| Term | Meaning |
|------|---------|
| **Predictability** | Same process every run, not identical output |
| **Context load** | Tokens spent keeping skill descriptions in the always-on catalog |
| **Cognitive load** | Human memory cost of remembering user-invoked skill names |
| **Leading word** | Compact pretrained concept that anchors behavior (e.g. *seam*, *tracer bullet*) |
| **Branch** | Distinct path through a skill for a distinct use |
| **Completion criterion** | Checkable condition that a step is done |
| **Context pointer** | Link/instruction that loads a reference file only when needed |
| **Progressive disclosure** | L1 metadata → L2 SKILL.md → L3 references/scripts |
| **Router skill** | User-invoked skill that indexes other user-invoked skills |
| **Premature completion** | Ending a step before the criterion is met |
| **No-op** | Instruction that does not change default model behavior |
| **Sediment** | Stale content kept because removal felt risky |
| **Sprawl** | Skill too long even when every line is live |
